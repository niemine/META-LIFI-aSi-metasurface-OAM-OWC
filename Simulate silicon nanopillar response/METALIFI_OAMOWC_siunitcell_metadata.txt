Manuscript/Project Topic: Optical wireless communication with OAM beams generated by amorphous silicon metasurface
Project Description: 
This dataset characterizes the optical response of amorphous silicon (a-Si) nanopillars for metasurface design. It contains simulation files and scripts used to determine the phase accumulation and transmission efficiency of unit cells across a broadband wavelength range (1214 nm - 1550 nm). The resulting data underpins the design of Orbital Angular Momentum (OAM) generating metasurfaces used in the METALIFI project.

--------------------------------------------------------------------------------
EXPERIMENT/SIMULATION DETAILS
--------------------------------------------------------------------------------
Methodology: 
Numerical simulation using Rigorous Coupled-Wave Analysis (RCWA) to sweep geometric parameters of the unit cell.

Software Environment:
1. Ansys Lumerical FDTD/RCWA (Release 2020 or newer recommended)
2. MATLAB (R2021b or newer recommended)

Physical Parameters Modeled:
- Material: Amorphous Silicon (a-Si) pillars on SiO2 (Glass) substrate.
- Unit Cell Period: 0.6 micrometers.
- Pillar Height: 1.0 micrometer.
- Wavelength Range: 1214 nm to 1550 nm (Step size: 24 nm).
- Sweep Parameter: Pillar Radius (0.07 µm to 0.205 µm).

Workflow Description:
1. "Silicon Nanopillar Simulation.fsp": Base Lumerical project file containing the definitions for the substrate, unit cell geometry, and the custom material "siliconEind" (a-Si refractive index data).
2. "Broadband silicon pillar phase data creation.lsf": Lumerical script that loads the .fsp file, configures the RCWA solver, performs a radius sweep for each wavelength, and exports data to .mat files. The Silicon Nanopillar Simulation.fsp needs to be open for the code to work.
3. "unit_cell_at_1310nm.m": MATLAB script that loads the generated 'radiusData1310.mat' file to visualize the phase and transmission response at the primary design wavelength (1310 nm).

--------------------------------------------------------------------------------
MATERIALS & QUANTITIES
--------------------------------------------------------------------------------
Input Files:
- Silicon Nanopillar Simulation.fsp (Lumerical Project File)
- Broadband silicon pillar phase data creation.lsf (Lumerical Script)
- unit_cell_at_1310nm.m (MATLAB Script)

Output Data Files (Generated by .lsf script):
- radiusData[Wavelength].mat (e.g., radiusData1310.mat, radiusData1550.mat)

Variables in Output (.mat files):
- radius: Array of pillar radii [meters].
- phase: Relative phase shift of the transmitted light [radians].
- Transm: Transmission efficiency [0 to 1].
- wavelength: Simulation wavelength [meters].
- height: Pillar height [meters].
- period: Unit cell period [meters].
