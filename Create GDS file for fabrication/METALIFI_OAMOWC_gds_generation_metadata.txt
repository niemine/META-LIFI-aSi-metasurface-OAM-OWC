Manuscript/Project Topic: Optical wireless communication with OAM beams generated by amorphous silicon metasurface
Project Description: 
This dataset contains the scripting workflow and output files for generating GDSII lithography masks used to fabricate OAM-generating metasurfaces. The scripts utilize pre-calculated phase (radiusData1310 from the 'siunitcell' experiment) to map target phase profiles to specific nanopillar geometries. The workflow automates the creation of polygon vertices and the writing of standard .gds files for electron-beam lithography.

--------------------------------------------------------------------------------
EXPERIMENT/SIMULATION DETAILS
--------------------------------------------------------------------------------
Methodology: 
Automated layout generation using Lumerical scripting. The process involves:
1. Calculating the required phase profile for a specific OAM mode and focal length.
2. Discretizing this phase profile into a set number of levels (12).
3. Mapping these levels to physical pillar radii using a lookup table (radiusData1310).
4. Generating polygon vertices for each unique pillar using the 'polystencil' command on the unit cell model.
5. Writing the final GDSII file.

Software Environment:
1. Ansys Lumerical (Release 2020 or newer recommended) - specifically for 'polystencil' and 'gds' commands.
2. MATLAB (for intermediate data handling within the Lumerical environment).

Physical Parameters Modeled:
- Design Wavelength: 1310 nm (implied by input data).
- OAM Modes generated: l=1 and l=2 (in the provided example loop).

Workflow Description:
1. "buildFabricationPatterns.lsf": Master script that loops through target OAM modes and executes the sub-routines.
2. "buildMetaSurface.lsf": Calculates the spatial phase distribution (OAM + Lensing) and maps grid positions to specific pillar radii values.
3. "create_vertices.lsf": Opens "unit_cell.fsp", applies the mapped radii to the model, and extracts polygon vertices for the GDS file.
4. "createGDS.lsf": Writes the physical coordinates and polygons to a .gds file.

Output Data Files:
- [Index]_OAM_[ModeNumber].gds (e.g., 1_OAM_1.gds, 2_OAM_2.gds)

Variables in Intermediate Files:
- phaseMask: 2D matrix of target phase values.
- pillarMask: 2D matrix of assigned pillar radii.
- vertices: Cell array containing polygon coordinates for the GDS.
