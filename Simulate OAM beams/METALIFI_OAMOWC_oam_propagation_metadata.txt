Manuscript/Project Topic: Optical wireless communication with OAM beams generated by amorphous silicon metasurface
Project Description: 
This dataset documents the simulation workflow for propagating Optical Angular Momentum (OAM) beams generated by metasurfaces. It connects the near-field phase data (from the 'siunitcell' experiment) to far-field propagation characteristics. The scripts calculate the propagation of OAM beams through free space, analyze their mode purity (OAM spectrum), and quantify optical efficiency across a broadband range (1214 nm – 1550 nm). These results are critical for assessing the performance of the designed metasurfaces for optical wireless communication.

--------------------------------------------------------------------------------
EXPERIMENT/SIMULATION DETAILS
--------------------------------------------------------------------------------
Methodology: 
1. Near-Field Stitching: Constructing the full metasurface near-field by mapping unit cell responses (radius/phase data) to a spatial grid based on the target OAM phase profile.
2. Vector Propagation: Using Lumerical's far-field projection methods to propagate the stitched fields to a specific distance.
3. Mode Analysis: Decomposing the propagated complex fields into OAM power components using MATLAB to determine mode purity.
4. Efficiency Calculation: Integrating power flux at the input, near-field, and far-field planes to determine transmission and propagation losses.

Software Environment:
1. Ansys Lumerical FDTD (Release 2020 or newer recommended) - for field propagation.
2. MATLAB (R2021b or newer recommended) - for mode decomposition and analysis.

Physical Parameters Modeled:
- Lens Radius: 49.9 micrometers.
- Focal Length: 100 micrometers.
- Input Beam: Gaussian (w0 = 30 micrometers).
- OAM Modes: l = -5 to +5 (excluding l=0).
- Wavelength Range: 1214 nm to 1550 nm (Step size: 24 nm).
- Propagation Distance: ~100 micrometers (tunable).

Workflow Description:
1. "propagate_OAMbeams_broadband.lsf": Master Lumerical script. It loops through wavelengths and OAM modes, calls "functionLibrary_broadband.lsf" to stitch the near field, propagates it to the far field, and saves the complex field distribution to 'beamData...' files.
2. "broadbandloop_power.lsf": A parallel script that saves the raw near-field data (before and after the lens) to 'nearFieldData...' files for efficiency calculations.
3. "calculate_OAM_purities.m": MATLAB script that loads 'beamData' files, performs OAM mode decomposition, and saves the purity spectrum to 'OAMpurity_v2...' files.
4. "calculate_OAM_power_fractions.m": MATLAB script that loads both 'nearFieldData' and 'beamData' to calculate transmission efficiency and total power loss.
5. "plotOAM1310profile.m", "plotOAM1550profile.m", "PlotOAMbars.m", "plotOAMpurity.m", "powerLossPlots.m": MATLAB visualization scripts for generating final figures from the processed data.

--------------------------------------------------------------------------------
MATERIALS & QUANTITIES
--------------------------------------------------------------------------------
Input Files:
- radiusData[Wavelength].mat (Data dependency from 'siunitcell' experiment)
- functionLibrary_broadband.lsf (Helper functions for field stitching)

Output Data Files:
- beamData[Wavelength]l[Mode].mat (Propagated far-field complex E-fields)
- nearFieldData[Wavelength]l[Mode].mat (Input and immediate output fields at the lens)
- OAMpurity_v2_l[Mode].mat (Calculated mode purity vectors)
- powerLoss_l[Mode].mat (Calculated power efficiency vectors)

Key Variables:
- Ef: Propagated Electric field [V/m].
- purityMat: Matrix of OAM mode weights [Normalized Power].
- powerRatioVector: Total optical efficiency [Ratio 0-1].
- EH: Structure containing field data and coordinates.
